NOTES
  - Snap ML only runs its accelerator path for tree ensembles (BoostingMachine, RandomForest, DecisionTree, imported xgboost/lightgbm/onnx/pmml); sklearn HistGradientBoosting cannot be moved onto it directly.
  - A model can be optimised once; tree_format is chosen with optimize_trees() / import_model(). A freshly fitted model that is never optimised does not use the accelerator.
  - Hardware PAI counters (perf pai_ext NNPA_*) are exposed by the kernel but report <not supported> in this z/VM guest, so accelerator use is shown with the zdnn_matmul_op call-count shim instead.
  - Probabilities are on each model's own scale (class_weight=balanced); event metrics at a fixed threshold are therefore not directly comparable across model families.
  - total wall time 557 s; quick=False
